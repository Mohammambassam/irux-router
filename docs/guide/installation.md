# Installation

Before installing **irux-router**, make sure your project meets the following requirements.

## Requirements

- React 18 or later
- React DOM 18 or later

If you don't have a React project yet, you can create one using Vite.

---

## Install

Install irux-router using your preferred package manager.

### npm

```bash
npm install irux-router
```

### pnpm

```bash
pnpm add irux-router
```

### yarn

```bash
yarn add irux-router
```

---

## Verify the Installation

Once the package has been installed successfully, you're ready to start building your application with irux-router.

No additional configuration is required.
