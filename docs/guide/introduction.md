# Introduction

Welcome to **irux-router**.

**irux-router** is a lightweight client-side router built specifically for React. It provides a clean and intuitive API for building single-page applications without unnecessary complexity.

Whether you're building a small project or a growing application, irux-router helps you organize navigation with a simple and predictable routing system.

---

## Why irux-router?

irux-router was designed with a few simple goals in mind:

- Keep the API easy to understand.
- Stay lightweight and focused.
- Make routing predictable.
- Provide a great developer experience.
- Grow with your application.

---

## Core Principles

### Simplicity

The API should be easy to learn and use.

### Readability

Routes should be easy to read and maintain.

### Consistency

Every part of the API should feel familiar and predictable.

### Flexibility

Choose the routing style that best fits your project.

---

## Features

- Client-side routing
- Router component
- Route component
- Link component
- useNavigate hook
- useLocation hook
- createRoutes utility
- NotFound support
- Browser History API
